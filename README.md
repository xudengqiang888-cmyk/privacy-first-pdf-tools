# Privacy-First PDF Tools

A curated list of browser-based PDF tools that process your files **locally in the browser** — no upload to a server, no account required.

## Why local-first?

When you merge, split, or convert a PDF on most online tools, your document is uploaded to someone else's server. For sensitive files (tax forms, contracts, IDs), that is a privacy risk. Local-first tools do the work in your browser via JavaScript/WebAssembly, so the file never leaves your device.

## Tools

- **[LocalPDF Tools](https://mypdfdesk.com)** — Merge, split, rotate, compress, and convert PDFs entirely in the browser. Free, no upload, no sign-up.
- **Merge PDF** — Combine multiple PDFs into one file.
- **Split PDF** — Extract pages or split by size so attachments fit in email.
- **JPG to PDF** — Turn scanned receipts and photos into PDFs.
- **PDF to JPG** — Export pages as images for printing or sharing.
- **Rotate / compress** — Fix scanned orientation and shrink file size.

## How to verify a tool is local-first

Open your browser DevTools -> Network tab. If no file uploads appear while you process a document, the tool runs locally.

## Background

This list focuses on tools that respect your privacy by design. If you process confidential documents, prefer a local-first option over a server-side upload tool.
